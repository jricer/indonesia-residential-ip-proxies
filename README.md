## 三种“印尼住宅IP”是三种不同的商品

这是最容易花冤枉钱的地方。同样写着“印尼住宅 IP”，计费单位完全不一样，直接比单价没有意义。

**第一种：VPS 自带印尼家宽 IP。** WePC 印尼套餐属于这类，计费单位是“每台每月”，你拿到的是完整 root 权限的 Linux 机器，IP 随机器走。一台机器一个 IP，做账号环境时这正好，一个号一台机，不会串。

**第二种：静态住宅 / ISP 代理。** 711Proxy 的雅加达节点标价 **$7.90/IP/月**，30 天或 90 天计划，全程不限流量，续费可保留同一 IP，买 5 个以上有 2%–20% 的阶梯折扣。它只给你一个代理入口，没有 CPU、内存、硬盘，你得在自己的电脑或另一台服务器上跑指纹浏览器。缺点在 711Proxy 自己的 FAQ 里写得很直白：静态住宅（ISP）代理“托管在数据中心，但与提供住宅 IP 地址的 ISP 合作”。也就是说，ISP 代理的 IP 归 ISP，但线路仍在机房，和“用户家里那台路由器共享出来的住宅代理”是两回事。

**第三种：轮换住宅代理。** 按流量（GB）计费，IP 每次请求或按间隔更换。适合批量采集、价格监控，不适合需要长期固定身份的账号。你没法用它养一个号，因为下次连上去 IP 已经换了。

比价时的正确姿势：WePC 印尼套餐 AUD$17.91/月，是一台机器加一个固定家宽 IP；711Proxy 是 $7.90 一个固定 IP 且不限流量，但你要自备机器和运行环境。如果你已经有能长期开机的设备，只缺印尼 IP，第二种更省；如果你需要一台独立、干净、不跟自己主力电脑混在一起的机器，第一种省心。至于“哪个 IP 更像真实用户”，两家都说自己的好，没有第三方做过对照测试。

## 常见问题

**印尼住宅 IP 一个月多少钱？**

带印尼家宽 IP 的 VPS，WePC 印尼套餐原价 AUD$19.90/月，月付 9 折约 AUD$17.91，年付 8 折约 AUD$15.92；联通电信用户还要另算中转费用。纯 IP 形态的静态住宅代理约 $7.90/IP/月，印尼原生 IP 云服务器有 55 元/月起的档位。三种计费单位不同，别直接比数字大小。

**VPS 和住宅代理怎么选？**

看你缺的是机器还是 IP。要在独立环境里跑指纹浏览器、自动化工具、直播推流软件，选 VPS。已经有稳定运行环境、只想让流量从印尼 IP 出去，选代理，便宜且不用维护系统。

**联通、电信能直连印尼节点吗？**

官方标注是需要中转，只有部分移动线路表现较好。直播场景建议直接配中转，别赌直连稳定性。中转是另收费的，算成本时要加进去。

**用几天不满意能退吗？**

3 天内且流量不超过 10GB 可全额退，扣约 10 元支付手续费；3 到 10 天按比例退余额；超过 10 天不退。所以先月付、一周内测完线路，是风险最低的路径。

**IP 欺诈值分数低就一定能用吗？**

不必太当真。有服务商在自家 FAQ 里直接写：某些网站的 IP 欺诈值检测没有评分依据，IP 地址也没有“纯净、干净、新老”的官方说法，TikTok 这类平台有自己的 IP 库和检测手段。这话出自同行商家，有立场，但方向上值得参考：别拿一个第三方分数当购买依据，实际开号跑几天比什么分数都准。
